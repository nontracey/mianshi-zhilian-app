# Agent 改造落地审计

更新：2026-09-13。范围：基线 `df84997` 上的整个工作区，包括尚未跟踪的教练模块。原计划仍是验收基准。**主链路已接入默认首页，但完整 V1 尚未验收通过。** 本文区分代码实现、本地测试、真实服务和设备验证，不用测试数量代替产品验收。

## 已接通的主链路

- 默认三入口：今天、目标与资料、模拟。启动不再加载旧内容服务，CI 移除了外部 content 仓库依赖；旧资料保留为迁移与归档来源。
- JD/简历随现有 AI 配置调用模型，离线回退；要求可编辑并追加目标修订。项目事实必须锚定原文，未确认主张不升级为个人经历。
- PDF 使用 PDFium 实际解析，测试覆盖压缩中文/拉丁文本、分页以及无文本扫描件拒绝；DOCX 使用 XML 正文提取。未实现 OCR，不把扫描件当成功导入。
- 会话冻结 JD、简历、项目、考点和计划范围，保留原答、checkpoint、时长、题量、场次覆盖。自然语言转学习保留原模拟进度；语音输入先校对再发送。
- 模型提交受持久 run lease 约束，跨窗口迟到回复不能覆盖新一轮。上下文带真实消息 ID、预算内项目片段和可核对引用；被裁掉的问答不能参与评分。JSON 提案必须是完整对象或完整 JSON 代码块，不从普通文字中截取对象执行。
- 评价纠错可从场后报告发起：标记异议追加修订并重算进度，重评只用原问题、原答和可定位依据。保留所有旧评价，记录模型、规则哈希和实际 token 用量；没有依据仍待核实。未结束会话不能进入评分报告。
- 默认训练模板会参与每日计划；卡片连接实际 session 和 WorkflowRun，题量/时长生效，重复进入恢复原会话。已开始项目受计划调整保护，跳转、跳过不会推算未做卡片为完成；加学和加练使用独立额外批次。
- 工作流应用时若时间不够，明确选择延长或顺延；顺延卡片在次日按当时状态实例化为额外计划，不改基础分母。连续两次薄弱才选中同一知识点补讲，训练中途形成的薄弱也只追加一次；模板快照和已触发状态持久化。

## 招聘、MCP 与检索

- 智联公开页适配器已通过一次真实联网测试：生产 HTTP 客户端读取公开首批岗位、校验查询与页面状态，映射真实公司/薪资/时间和来源链接。结果明确为摘要、部分结果；城市仅在本批过滤。失败、验证页、页面结构变化均不冒充零结果。默认关闭，由用户启用。
- BOSS、猎聘、拉勾、智联提供本人打开平台的搜索入口。BOSS 公开响应没有可用岗位正文，未绕过登录/验证，也不宣称已在 App 内检索 BOSS。自定义 POST JSON 搜索服务继续可用，演示通道明确为合成数据。
- MCP 接入教练工具循环，服务和工具逐项授权，并单独授权发送本场材料；工具结果作为不可信来源，限制调用次数和长度。密钥只在安全存储中，按档案/服务/地址绑定。
- MCP 支持 2025-11-25 生命周期，以及 2026-07-28 每请求元数据和方法/参数头。OAuth 实现受保护资源发现、PKCE S256、state/issuer/resource 校验与刷新；目前需预注册的公共 client ID，没有自动注册客户端。没有真实 MCP 服务可供联调。
- 可选 Embedding 配置、安全凭据、批量向量、增量缓存和关键词降级已接通。尚无真实 Embedding 服务验收记录。

## 数据、删除与迁移

- 原生使用事务 SQLite；Web 接入同一 Drift schema 和官方 WASM/worker，拒绝纯内存及不安全的单标签降级。运行资源版本、校验和和许可随 Web 构建保存，Pages 响应头支持隔离存储。浏览器实际重启持久化仍需验证。
- 备份有 schema、表清单、计数、哈希与档案关系校验，事务恢复保护不可变原答。完整清除递增 reset generation、防旧设备复活，清理检索/向量缓存；SQLite secure_delete、checkpoint/VACUUM 经实际文件测试。混合场次的其他知识原答有保留边界，不能宣称删除单点即删除整场。
- 删除预览开放保留知识、清知识留记录、清知识和记录选择；提交重新核对引用/作答，默认保留已学资料。清理任务可重试，相关旧会话暂停。
- V2 同步复用 WebDAV/GitHub/Gitee，独立文件、冲突重试和新鲜本地快照合并；自动同步已接入，生成回复时延后恢复。教练 JD/简历/项目正文与原答各有独立、默认关闭的授权开关，旧版备考同步开关不会顺带授权教练材料。脱敏标记可穿过数据库恢复/再导出，空白副本不能抹掉本机原文。
- 进度按题组最新评价修订重放，同日双设备不重复升级；同版本计划/模板保留分支。同题组同修订不同评价先变为待裁决事件，不计成绩，两份评价保留；资料同版并发修改也隔离双方分块，裁决前两版均不进入检索。冲突页面可比较并选择计划、模板、评估或资料版本，选择后以更高修订收敛；本地合并顺序、再合并和隐私测试通过，尚无真实双设备验收。
- 参考资料正文可原位更新，新版本重新切块和检索，旧正文快照/分块保留用于历史引用；关联知识标为过期待核验，生成回复中拒绝更新。
- 旧目标、项目、模拟历史和练习原答幂等迁移；迁移前完整旧材料快照有哈希，提供归档查看、重试与导出。旧分数只存档，不冒充新证据；整批材料与练习迁移在同一事务中，内存失败回滚/重试和原生事务回滚通过。
