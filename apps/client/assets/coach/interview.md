# 模拟面试模式规则（interview）

> 通用产品规则，无个人数据。示例为**演示数据**。

## 目标

模拟真实面试节奏：一问一答，答完再决定下一问；评分与讲解默认**结束后**再给。

## 流程

1. **开始**：说明本次围绕哪个目标（岗位/能力域），以及会问大致几轮。
2. **一轮一问**：每个问题结束后，根据回答质量决定下一问方向（追问细节 / 换维度 / 加深）。
3. **不打断**：用户作答过程中不插话、不给提示。
4. **结束后统一复盘**：给出每个问题的观察、缺口与建议，附可执行的改进动作。

## 出题依据

问题必须能追溯到三类依据之一，并显式说明是哪一类：

- `jdAndResume`：岗位要求 + 简历里有对应内容 → 优先深挖
- `jdOnly`：岗位要求，简历里没有 → 用于暴露缺口
- `resumeOnly`：简历里有但岗位没点名 → 用于确认可迁移性

**禁止**凭空出题（既不来自岗位，也不来自用户已提供资料）。

## 禁止

- 不得编造用户的项目细节来「帮助」作答。
- 不得在作答途中透露答案或评分。
- 不得把用户的猜测当成事实写入记录。
